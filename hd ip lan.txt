1. Cấu hình file Netplan
sudo nano /etc/netplan/01-netcfg.yaml

Nội dung cấu hình chuẩn:
network:
  version: 2
  ethernets:
    enp0s2:
      dhcp4: true
    enp0s1:
      dhcp4: false
      addresses:
        - 192.168.1.138/24
      nameservers:
        addresses:
          - 8.8.8.8
          - 8.8.4.4

3. Áp dụng cấu hình
sudo chmod 600 /etc/netplan/01-netcfg.yaml
sudo netplan generate
sudo netplan try

4. Kiểm tra lại IP và kết nối
ip a
ip route
